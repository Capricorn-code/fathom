# fathom

AIとの開発履歴から「何をやったか」を言語化し(機能A)、「それが本当に身についているか」を検証する(機能B)ツール。

**発見ではなく、区別と確信のために。**

## 解決する課題

AI時代のエンジニアが:

1. 自分のスキルの成長を言語化できない
2. AIに書かせた成果を本当に理解しているか確信が持てない

fathomは「AIを使えばスキルが身についている」とは前提しない。サマリは帰属を断定せず(「あなたはXを実装した」ではなく「Xの実装が行われた。あなたの指示n回」)、検証を通った実績だけが確信になる。この誠実さがこの製品の軸である。

## 使い方(M1時点)

```sh
fathom summary <Claude CodeセッションログのJSONLパス>
```

セッションの期間・指示一覧・触ったファイル・エラー数・トークン量をまとめたMarkdownを出力する。解析対象はopt-in許可リストで明示したプロジェクトのみ。

## やらないこと

- BtoBの作り込み
- 組織ダッシュボード
- iOS化
- ゲーミフィケーション
