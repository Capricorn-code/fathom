# Changelog

このパッケージの変更履歴。書式は [Keep a Changelog](https://keepachangelog.com/ja/1.1.0/)、バージョニングは [Semantic Versioning](https://semver.org/lang/ja/) に従う(0.x系は開発版であり、マイナー更新で破壊的変更が入ることがある)。

## [0.2.0] - 2026-10-03

### 追加

- **引数なしの `fathom summary`**: 許可したプロジェクトのセッション一覧(新しい順)から番号で選んで実行できるように。ログのパスを知らなくても使えるのが基本の使い方になった(`--html` も同様に使用可)
- パス指定は引き続き可能(上級者向け)

## [0.1.0] - 2026-10-03

初回リリース。

### 追加

- `fathom summary <jsonlパス>`: Claude CodeのセッションログからサマリをMarkdownで出力
- `--html`: スタイル内蔵・外部依存なしの自己完結HTMLを生成(折りたたみつき)
- 会話の流れ表示: あなたの指示とAIの応答を時系列の対で表示(長い応答は要点3行+全文折りたたみ)
- 集計: 期間 / 触れられたファイルと回数 / 使用ツール / エラー数と回復記録 / トークン量(キャッシュ内訳つき延べ量)
- 初回対話セットアップ: 解析を許可するプロジェクトを選んで許可リストを自動生成(デフォルト全拒否のopt-in)

### 設計方針

- 完全ローカル処理(外部通信なし)
- サマリの文言は操作の主体(あなた/AI)を断定しない
