# fathom

**Claude Codeで、あなたは今日何をやった?** — AIに書かせてばかりで、自分が何をどこまで理解しているか不安になっていませんか。

fathomは、Claude Codeが自動保存しているセッションログを読み、**「あなたの指示」と「AIの応答」を対にした5分で読めるサマリ**(Markdown / HTML)に変換するローカルCLIです。

- **発見ではなく、区別と確信のために。** 「これは人に説明できる/ここは説明できない」を区別する材料を提供します
- **完全ローカル。** ログがあなたのマシンの外に送られることはありません(外部通信するコードが存在しません)
- **帰属を断定しません。** 「あなたはXを実装した」とは書かず、「Xの編集が行われた。あなたの指示n回」と記録そのままに表現します。AIがやったことを自分の実績のように盛る道具ではありません

## インストール

Node.js 22以上が必要です。

```sh
npm install -g @haruto-y/fathom
```

## 使い方

```sh
fathom summary          # セッション一覧から選んでMarkdownを出力
fathom summary --html   # 同じく選んで、ブラウザで読める自己完結HTMLを生成
```

実行すると、許可したプロジェクトのセッションが新しい順に並ぶので、番号を選ぶだけです。

```
サマリを見るセッションを選んでください(新しい順):

1. /Users/you/hobby/app(2026-10-03 12:30)
2. /Users/you/oss/tool(2026-10-01 09:12)

番号:
```

ログのパスが分かっている場合は `fathom summary <JSONLパス>` の直接指定もできます(Claude Codeのログは `~/.claude/projects/` 配下にあります)。

### 初回セットアップ

設定なしで実行すると、解析を許可するプロジェクトを選ぶ対話セットアップが起動します:

```
fathomの初回セットアップです。解析を許可するプロジェクトを選んでください。
⚠ 業務プロジェクトは選ばないでください(個人リポジトリ/OSSのみ)。

1. /Users/you/hobby/app
2. /Users/you/oss/tool

解析を許可する番号(カンマ区切り):
```

**選んだプロジェクト以外のログは、fathomは一切読みません**(デフォルト全拒否のopt-in方式)。

### 出力の例

```markdown
# セッションサマリ: 8bbf611f-…

> このサマリはセッションログの機械的な集計です。
> 記録された操作の主体(あなた/AI)を断定しません。

## あなたの指示とAIの応答

### 1. 認証まわりをリファクタして
認証ロジックをmiddlewareに分離します。まずテストから…
<details><summary>応答の全文(42行)</summary>…</details>

### 2. テストが落ちてる、直して
原因はモックの初期化順でした。…

## 詳細
76ファイルへの編集 / エラー6件(うち6件はその後成功) / トークン量 …
```

## プライバシーについて

- **外部送信ゼロ:** 解析・サマリ生成はすべてローカルで完結します。LLM APIも呼びません
- **opt-in方式:** 許可リスト(`~/.config/fathom/config.json`)に明示したプロジェクトのログしか読みません。デフォルトは全拒否です
- **業務コードでの利用は推奨しません:** セッションログには業務情報が含まれえます。個人リポジトリ・OSSでの利用を前提に設計しています
