# ADR-001: 2サービスではなく1サービスとして作る

## 状況

fathomには「何をやったかの言語化(機能A)」と「身についているかの検証(機能B)」という性格の異なる2機能がある。別プロダクトとして分けるか、1サービスに載せるかの判断が必要だった。

## 決定

**1サービスとして作る。** ログ解析基盤(パーサー・データモデル)を共有し、機能A/Bをその上の2つの入口として載せる。

## 却下した代替案

- **機能A/Bを別サービス・別リポジトリで作る:** 両機能とも同じセッションログ解析を必要とするため、基盤が二重になる。副業の限られた時間(週5〜15時間)で二重メンテは成立しない。また機能A(無料)から機能B(有料)への導線が製品の収益モデルの前提であり、分離するとこの導線が切れる。
