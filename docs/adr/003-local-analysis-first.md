# ADR-003: ローカル解析を最大化し、LLMにはSessionDigestのみ送る

## 状況

セッションログには業務・個人を問わず機微な内容(コード、パス、プロンプト)が含まれうる。サマリの言語化にLLMを使う場合、何をどこまで送信するかは製品の信頼性を左右する。

## 決定

**解析はローカルで最大限行い、LLMに送るのは正規化済みSessionDigest(層3)のみとする。** さらに送信前にマスキング済み内容をユーザーにプレビューさせ、編集可能にする。

※M1ではLLM連携自体を実装しない。この決定は型と構造(層3だけが送信可能)として先に効かせる。

## 却下した代替案

- **生ログをそのままLLMに送る:** 実装は最も簡単だが、コード本体・tool_result生データ・diffが外部送信され、ターゲット(業務でAIを使う開発者)には受け入れられない。
- **完全ローカル処理(LLM不使用):** 言語化の質が頭打ちになり、機能Aの価値(5分で読めるサマリ)が成立しない。
