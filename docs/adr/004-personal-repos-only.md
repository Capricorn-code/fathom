# ADR-004: 検証・ドッグフーディング対象は個人リポジトリ/OSSのみ

## 状況

fathomの開発・検証には実際のセッションログが必要。開発者は会社員であり、業務でもAIコーディングツールを使用しているため、業務コードのログを検証に使う誘惑がある。

## 決定

**検証・ドッグフーディングの対象は個人リポジトリとOSSのみとする。業務コードは扱わない。**

## 却下した代替案

- **業務コードのログも検証に使う:** ログには業務コードの断片やプロジェクト情報が含まれ、就業規則・秘密保持義務との衝突リスクがある。副業プロダクトの検証のために本業の信頼を賭けるのは割に合わない。[ADR-007](./007-personal-equipment.md)(個人機材のみ)と合わせて、業務資産との分離を徹底する。
