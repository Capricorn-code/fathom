# ADR-004: 検証・ドッグフーディング対象は個人リポジトリ/OSSのみ

## 状況

fathomの開発・検証には実際のセッションログが必要。業務・組織のコードのログを検証対象にしたくなる場面がありうる。

## 決定

**検証・ドッグフーディングの対象は個人リポジトリとOSSのみとする。業務コードは扱わない。**

## 却下した代替案

- **業務コードのログも検証に使う:** ログには業務コードの断片やプロジェクト情報が含まれ、秘密保持義務との衝突リスクがある。個人プロダクトの検証のために負うべきリスクではない。[ADR-007](./007-personal-equipment.md)(個人機材のみ)と合わせて、業務資産との分離を徹底する。
