# ADR-006: 解析対象はopt-in許可リスト方式

## 状況

`~/.claude/projects/` には業務・個人を問わずすべてのプロジェクトのログが混在して蓄積される。fathomがどのログを読んでよいかを決める仕組みが必要。

## 決定

**opt-in許可リスト方式とする。デフォルトは全拒否。** 設定(`~/.config/fathom/config.json`)で明示されたプロジェクト以外、パーサーはファイルを読めない。初回実行時に対話的セットアップで一覧を提示し、「業務プロジェクトは選ばないでください」と明示した上でユーザーに選択させる。

## 却下した代替案

- **opt-out方式(デフォルト全許可):** 初回体験は滑らかになるが、業務プロジェクトのログを意図せず解析する事故が構造的に起こりうる。[ADR-004](./004-personal-repos-only.md) の「業務コードを扱わない」を、ユーザーの注意力ではなく仕組みで担保するにはopt-inしかない。
