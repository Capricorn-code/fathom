# ADR-007: 開発・検証・ログ蓄積はすべて個人機材・個人アカウントで行う

## 状況

fathomは個人開発である。組織の機材やアカウントを流用すると効率的な場面もあるが、成果物の帰属が曖昧になる。

## 決定

**開発・検証・ログ蓄積はすべて個人Mac・個人アカウント(GitHub / Claude)で行う。会社資産には一切触れない。** devcontainerは使わずホスト直運用とし、ログは `~/.claude/projects/` に自然に永続化させる(これが機能Aの入力データになる)。

## 却下した代替案

- **会社機材・アカウントの併用:** 成果物の知的財産の帰属が争点になりうる。資産の分離は「確認した」ではなく「構造的に混ざらない」状態で維持する。[ADR-004](./004-personal-repos-only.md) とあわせて、業務との境界を機材レベルで引く。
