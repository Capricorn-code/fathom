# ADR-008: パーサーのGo移植は機能Bリリース後に検討(予約のみ)

## 状況

77MB級のJSONLを扱うため、パーサーの性能が将来問題になる可能性がある。Goで書き直せば高速化と単一バイナリ配布が見込めるが、今やるべきかの判断が必要だった。

## 決定

**Go移植は機能B(M3)リリース後に検討する。予約のみで、着手しない。** M1〜M3はTypeScriptのストリーム処理(readline + createReadStream)で進める。

## 却下した代替案

- **最初からGoで書く:** 開発者の主戦場がTypeScriptであり、zodによるスキーマ寛容なパースやCLI開発の速度で劣る。性能はストリーム処理で当面足りる。
- **移植の完全放棄:** 将来npm配布物の起動速度や解析速度がボトルネックになった場合の選択肢として残す価値はある。ただしBACKLOG的な予約に留め、Issue化はしない。
