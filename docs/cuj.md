# クリティカルCUJ

クリティカルなユーザージャーニーは**1本のみ**。これ以外のジャーニーの最適化はしない。

## ジャーニー

> AIに書かせてばかりで実力に不安を持つ開発者が、
> インストール → 実行 → **5分以内に出力を読み、「これは人に説明できる/ここは説明できない」と区別できる感覚を得る**まで。

## 要点

- **最重要は出力の質。** 5分以内に読めて、区別の感覚が得られるサマリであること
- 摩擦削減のため、初回実行時の対話的セットアップを含める(設定なしで実行した場合、`~/.claude/projects/` の一覧から解析対象を選ばせて許可リストを生成する。詳細は [spec/feature-a.md](./spec/feature-a.md))
- サマリの文言は帰属を断定しない([product.md](./product.md) の設計思想を参照)

## このCUJが満たされたことの確認方法

開発者自身がfathomリポジトリの開発ログをfathomに食わせ、出力されたMDを読んで「説明できる/できない」の区別ができるか自分で確かめる(ドッグフーディング。M1の完了条件と同一)。
